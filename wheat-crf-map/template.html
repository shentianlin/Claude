方法、参数与需要您实测的数据

1. 释放的温度模型

控释期 D 按国标口径定义为 25 °C 静水中累计释放 80% 的天数。温度只改变释放速度，不改变曲线形状（Hara 2000），所以把逐日 5 cm 土温按 Arrhenius 方程折算成 25 °C 等效天数，再代入 25 °C 下的释放曲线。小麦田不淹水，释放比静水慢，土壤系数取 0.80（Du 2006 在湿润介质中测得的释放慢于静水）；土温 0–3 °C 之间释放按比例降到零，冻土期视为停止释放。

a(T) = exp[ Ea/R · (1/298.15 − 1/(T+273.15)) ] · min(1, max(0, T/3)) τ(t) = f_soil · Σ a(T_d) （25 °C 等效天数） F(τ) = f0 + (1−f0)·[1 − exp(−(τ/λ)^β)] λ = D / [ln((1−f0)/0.2)]^(1/β) （保证 F(D)=80%） 土温 = 气温 + 1 °C；气温 < 0 °C 时取 0.4·气温 + 0.5（积雪与土层缓冲）

Ea 取 50 kJ/mol（20–30 °C 间 Q10≈2，Gandeza 1991）；实验室测得 37–46 kJ/mol（Du 2006），国产包膜尿素 Q10 为 1.4–2.8（Liu 2011）。小麦生长季土温低，季内累计只有 50–85 个 25 °C 等效天，所以 Ea 取值对结果的影响比水稻大。

2. 小麦需氮模型

作物累计吸氮比例是积温进度 x = GDD(t)/GDD(收获) 的 S 形曲线（基温 0 °C），由两点标定：拔节期与开花期的累计吸氮比例。拔节到开花是吸氮高峰，与产量、氮效率关系最密切（Duan 2019）；开花后吸氮约占 12–24%，高蛋白品种偏高（Lollato 2021）。返青前一次施用的地区（西欧）不计冬前吸氮。

3. 肥料氮库与优化

库(t+1) = 库(t)·(1 − k(T)) + 当日释放 − 当日吸收/η k(T) = k20 · 2^((T−20)/10) · wet （低温损失小，多雨区 wet>1） 约束（管饱）：库(t) ≥ max(拔节前库存下限, 未来 7 天需求) 目标（不浪费）：总施氮量最小

对“尿素 + 至多 2 个控释期”的每个组合（30–360 天共 34 档）解一次线性规划，比例按 5% 取整后再求满足约束的最小总量。成熟时没释放完的氮、前期释放过早而损失的氮，都会自动计入总量。

默认参数

要把模型从“文献初值”变成“您的产品”，需要实测这些数据

  1. 每个控释期档位的 Ea 与 β：15、20、25、30、35 °C 五个温度的静水释放曲线。拟合出的 β 比 Ea 更关键，它决定产品是“线性释放”还是“S 型”。
  2. fsoil 与冻土行为：在代表性麦田埋网袋（秋播—越冬—返青各取样），同时记录 5 cm 土温和土壤含水量；重点确认 0–5 °C 与冻融交替时的实际释放。
  3. 各区 INS：多点无氮区的地上部吸氮量。
  4. k_loss 与 η：用 15N 微区试验或氮素表观平衡标定；本版取值使基追各半的尿素回收率约为 40–50%。
  5. 气温：本版用各站月均温插值；正式版应改用 ERA5 或 NASA POWER 近 20 年逐日数据，并按年份逐一检验。

局限

  • 农时、产量、INS、当地常规施氮量取自文献与公开统计的代表值，同一产区内品种、土壤、降水差别很大。
  • 模型假定土壤湿润。旱作区（黄土高原、大平原、西澳、哈萨克斯坦）表土常干，包膜释放会进一步变慢，需要埋袋实测。
  • 包膜尿素比尿素更适合与种子同沟或近种施用，但尿素部分仍应与种子隔开 3–5 cm，以免烧种。
  • 强筋小麦若要达到蛋白质标准，常需在孕穗—开花期补少量氮；一次施肥方案以产量为目标。
  • 只计算氮。磷、钾请按土壤测试一次基施，可一并掺入。
  • 欧盟《肥料产品法规》(EU) 2019/1009 对包膜聚合物可降解性有期限要求；硝酸盐指令限制秋季施氮。

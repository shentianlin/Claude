# 麦季控释配方地图

全球 33 个小麦产区的“包膜尿素 + 尿素”一次施用掺混配方模型，结构与 `../rice-crf-map` 相同。

与水稻版的差别：

- 旱地土壤：释放系数 f_soil = 0.80；土温 = 气温 + 1 °C，负温时取 0.4·气温 + 0.5；土温 0–3 °C 线性降到零（冻土停止释放）。
- 氮库日损失率随土温变化：k(T) = k20 · 2^((T−20)/10) · wet，多雨地区 wet > 1。
- 需氮曲线由拔节期、开花期累计吸氮比例标定，生育期直接取当地农时。
- 西欧（法、英、德）因秋季禁施氮，方案为返青前一次施用。

运行：

```bash
pip install numpy scipy
python3 build.py
```

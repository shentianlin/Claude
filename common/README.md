# 共用模块：环境效应

`env.py` 为水稻、小麦两张地图计算每个季别三种方案（农户常规 FP / 同标准分次施尿素 OPT / 推荐控释掺混 CRF）的：

- NH₃ 挥发、直接与间接 N₂O、淋溶径流（排放因子 × meta 分析减排比例，仿 Gu et al. 2023 Nature）；
- 化肥相关温室气体与碳足迹（LCA，摇篮到农场大门）、氮足迹（kg Nr/t）；
- 社会损害成本（单位损害成本 × 损失量，N₂O 与生产排放按碳价）；
- Monte Carlo 5–95% 区间，以及“减量效应 / 控释效应”分解。

`env_section.html` 与 `env.js` 由两个 `build.py` 注入到各自页面。所有参数都在 `env.py` 顶部，可用实测值替换。

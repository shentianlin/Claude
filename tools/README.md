# 静水释放曲线拟合工具

把各档产品的“天数—累计释放%”数据填进 CSV，`fit_release.py` 会逐档拟合

    F(t) = f₀ + (1 − f₀) × [1 − exp(−(t/λ)^β)]

并输出：

- **控释期 D**：拟合曲线累计释放 80% 的天数；数据测到 80% 以上时，同时给出实测插值值作对照。
- **形状参数 β**：< 1.8 判为线性型，≥ 1.8 判为 S 型（有滞后期）。
- **初期溶出 f₀**：λ 由拟合得到，另给出释放 10%、50% 的天数和日释放高峰。
- **拟合优度**：R² 和 RMSE（单位为百分点）。结果可疑时，“提示”列会说明原因，例如 D 是外推值、拟合一般、残差偏大。
- **表观活化能 Ea**：同一档位有两个及以上温度的数据时，按 Arrhenius 方程估算，并判断 β 是否随温度变化。
- **对比图**：每个档位一幅小图，圆点是实测值，实线是拟合曲线，不同温度用不同颜色。

## 用法

```bash
pip install numpy scipy matplotlib
python tools/fit_release.py 我的数据.csv              # 结果写到数据文件旁边的 fit_output/
python tools/fit_release.py 我的数据.csv -o 结果目录
python tools/fit_release.py 我的数据.csv --fix-f0 3  # 早期取样少时，把初期溶出固定为 3%
```

输出两个文件：`fit_results.csv`（可用 Excel 打开）和 `fit_curves.png`，终端同时打印汇总表。

## 数据格式

可以直接复制 `template_release.csv` 来填，也可以从 Excel 另存为“CSV UTF-8”。支持两种格式。

**长表**：每行一个数据点。温度一列可省略，省略时按 25 °C 处理。

| 档位 | 天数 | 累计释放% | 温度 |
|---|---|---|---|
| CR90 | 1 | 2.8 | 25 |
| CR90 | 7 | 9.5 | 25 |

**宽表**：第一列是天数，其余每列一个档位，列名就是档位名。第二列可以是温度。

| 天数 | CR60 | CR90 | CR120 |
|---|---|---|---|
| 1 | 3.1 | 2.8 | 2.5 |
| 7 | 14.2 | 9.5 | 7.1 |

- 列名中英文都认：档位/grade、天数/day、累计释放/release、温度/temp。
- 空格子会被跳过。
- 累计释放写成 2.8 或 0.028 都可以。

## 取样建议

- 在第 1、3、7、14、21、28、42、56、70、90、120 天……取样，一直测到超过 80%。没测到 80% 时，D 是外推值，准确度会下降。
- 要估算 Ea，同一档位至少测 2 个温度，最好测 15、25、35 °C 三个。
- S 型产品要重点加密前期取样，这样才能看清滞后期。

## 把结果用到配方地图

- 线性型产品：把 β 中位数填入 `rice-crf-map/params.toml` 的 `[release] beta`。
- S 型产品：填入 `[scenarios] stype_beta`。
- Ea：填入 `[release] Ea`。
- 改完后重新运行 `python build.py`。

## 示例

`example_release_simulated.csv` 是按模型公式加随机误差**模拟**的示例数据，不是任何真实产品的测定值。它用来检验工具能否还原已知参数：模拟时设定 D=60/90/120 天、线性型 β=1.3、S 型 β=2.5、Ea=50 kJ/mol，拟合结果在 `example_output/`。

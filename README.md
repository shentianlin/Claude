# 控释掺混肥配方地图

| 目录 | 内容 |
|---|---|
| `rice-crf-map/` | 稻季控释配方地图：50 个稻作区、73 个稻季。模型代码包、参数文件、数据、页面生成脚本齐全，见该目录的 README。 |
| `wheat-crf-map/` | 麦季控释配方地图：33 个小麦产区（结构同水稻版的早期形式：`model.py`、`zones.py`、`build.py`）。 |
| `common/` | 两张地图共用的模块：环境效应（氨挥发、N₂O、淋溶径流、碳足迹、社会损害成本）与 S 型产品情景。 |
| `analysis/` | 专题分析：线性型 + S 型混合掺混的评估。 |

所有参数都是文献初值，需用实测数据标定。
| `field-release/` | 田间释放模拟器：按种植系统、施肥方式、土壤水分与温度，把 25 °C 静水释放换算成田间释放（模型在 `common/field_release.py`）。 |
| `tools/` | 静水释放曲线拟合工具：从实测数据拟合 D、β、f₀、Ea。 |

# 田间埋袋释放试验：数据模板与分析脚本

配合试验方案《包膜尿素田间埋袋释放试验方案》使用。各试验点按 `templates/` 中的 7 个 CSV 填写数据，
`analyze.py` 用两套输入运行田间释放模型（`../common/field_release.py`），算出误差，并做留一站点标定。

| 运行 | 输入 | 回答的问题 |
|---|---|---|
| A：实测驱动 | 埋袋深度的逐时土温、实测土壤水分、管理日志 | 模型本身准不准 |
| B：气象驱动 | 日最高/最低气温、降水、管理日志 | 只有气象数据时还准不准（推广时的真实情况） |

## 用法

```bash
pip install numpy scipy matplotlib
python validation/analyze.py 数据目录              # 结果写到 数据目录/output/
python validation/analyze.py 数据目录 -o 结果目录
```

试运行示例数据：

```bash
python validation/make_example.py                 # 重新生成 example/（模拟数据）
python validation/analyze.py validation/example
python -m unittest validation/test_validation.py  # 基本检查，约 3 秒
```

## 数据模板（`templates/`）

每个表都可以用 Excel 编辑，保存时选“CSV UTF-8”。以 `#` 开头的行是示例，分析时忽略。日期写成
`2027-06-05` 或 `2027/6/5`，时间写成 `2027-06-05 14:00`。列名中英文都认（见 `analyze.py` 中的 `COLS`）。

| 文件 | 每行是 | 必填列 | 说明 |
|---|---|---|---|
| `sites.csv` | 一个站点 | 站点、纬度、种植系统、质地、施肥日期 | 种植系统填 `field_release.py` 中的代码（见下）；质地填 黏土/壤土/砂土。实测了水分特征曲线的，填 van Genuchten 参数 `theta_r`、`theta_s`、`alpha_per_kPa`、`n_vg`，否则按质地取默认值 |
| `products.csv` | 一个产品（批次） | 产品、D_天 | 来自实验室定标（`tools/fit_release.py`）：D、beta、f0（%）、Ea_kJ、破损率（%）。空着的用模型默认值 |
| `bags.csv` | 一个取回的网袋 | 站点、产品、施肥位置、取样日期 | 填“初始氮_g + 剩余氮_g”，或直接填“累计释放%”。施肥位置：混施/条施/侧深施/表施。第 0 天对照袋也填进来 |
| `soil_temp.csv` | 一个土温读数 | 站点、时间、土温_C | 记录器导出的逐时数据直接粘贴。施肥位置列可空（表示该站所有处理共用）；表施处理最好有单独的地表记录器 |
| `soil_moisture.csv` | 一个水分读数 | 站点、时间，含水量或基质势二选一 | 含水量为体积含水量 m³/m³（或 %）；张力计读数填基质势 kPa。称重法只在取袋日测一次也可以 |
| `weather.csv` | 一天 | 站点、日期 | 最高、最低气温和降水（运行 B 的全部输入）。只有平均气温时，土壤水分改用种植系统预设 |
| `management.csv` | 一个事件 | 站点、日期、事件 | 事件：淹水、排水（晒田/落干）、灌溉（填水量_mm）、覆膜、揭膜、收获 |

种植系统代码：`rice_flooded`（水稻淹水）、`rice_awd`（干湿交替）、`rice_dsr`（旱直播后淹水）、
`wheat_irrigated`、`wheat_rainfed`、`maize_open`、`maize_film`（地膜）、`notill_residue`（免耕秸秆覆盖）。

## 分析做了什么

1. **逐日环境**
   - 运行 A：每天的温度因子由当天逐时土温直接对 Arrhenius × 冻结因子求平均（一天少于 12 个读数算缺测，缺测日用气温估算并在报告中提示）；土壤水分由含水量经水分特征曲线换算为基质势，缺测 ≤ 21 天的线性插值；淹水日基质势取 0。
   - 运行 B：土温 = 气温 + 种植系统预设偏移（与地图模型相同）；土壤水分用 200 mm 单层水量平衡估算（降水 + 灌溉 − Hargreaves 蒸散 × 作物系数，覆膜期蒸散按 60%，冬季降水先积雪），淹水日取 0。
2. **释放**：逐日速率 = 温度因子 × 水分因子 × 施肥位置系数 × 质地系数 × f_soil，代入产品自己的 D、β、f₀、破损率。
3. **误差**：每个“站点 × 产品 × 施肥位置”计算 RMSE、平均偏差，以及释放 50%、80% 的天数（d50、d80）的实测与预测值。
4. **合格标准**：RMSE ≤ 8 个百分点；d80 误差 ≤ ±10 天或 ±15%（取大者）；运行 B 的 RMSE ≤ 运行 A 的 1.5 倍（或 B 本身 ≤ 8）。
5. **标定**：用运行 A 的残差，带先验地拟合 f_soil、水分敏感度 s、条施和表施系数、黏土和砂土系数；没有对应数据的参数保持默认。
6. **留一站点验证**：每次去掉一个站点，用其余站点标定，再预测去掉的站点。这一结果代表模型推广到新地区的真实表现。

## 输出

| 文件 | 内容 |
|---|---|
| `report.md` | 总体误差、各站点 B/A、标定参数、土温实测与估算对比、各组合明细、数据提示 |
| `metrics.csv` | 每个组合 × 参数（默认 / 留一站点标定 / 全部数据标定）× 运行的误差和是否合格 |
| `observed_vs_predicted.csv` | 每次取样的实测均值、标准差、袋数和各情景预测值 |
| `calibration.csv` | 标定参数，含每一折留一站点的值 |
| `daily_inputs.csv` | 逐日气温、实测与估算土温、两套基质势、淹水与覆膜状态 |
| `fig_站点.png`、`fig_scatter.png` | 各站点释放曲线；预测与实测散点图 |

## 示例数据（`example/`）是模拟的

`example/` 中的数据全部由 `make_example.py` 生成，**不是实测数据**。生成时设定了一组“真实”参数
（f_soil 0.80、s 0.35、条施 0.80、表施 2.0、黏土 1.10、砂土 0.95），合成了 4 个站点（湖北中稻、河南灌溉冬小麦、
陕西旱作冬小麦、甘肃地膜玉米）的气象、逐时土温、土壤水分和取袋数据（每袋误差标准差 2.5 个百分点）。

在这套数据上：默认参数的合并 RMSE 约 7.7 个百分点，留一站点标定后约 3.9（A）和 3.5（B）；f_soil、条施、表施系数
基本找回了设定值。砂土系数（1.06，设定值 0.95）和水分敏感度（0.30，设定值 0.35）只部分找回，因为唯一的砂土站点
同时也是唯一的旱作站点，两者的影响分不开。报告会自动标出这类“只有 1 个站点数据”的参数。正式试验选点时，
应让同一种质地或施肥位置至少出现在 2 个气候不同的站点。

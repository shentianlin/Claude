# 玉米控释配方地图

全球 28 个玉米产区的“包膜尿素 + 尿素”播种时一次基施掺混配方模型，结构与 `../wheat-crf-map` 相同。

与小麦版的差别：

- **释放直接用田间释放模型**（`../common/field_release.py`，与田间释放模拟器相同）：
  - 包膜处土温：露地为气温 + 1 °C；地膜前 60 天为 + 3.5 °C，之后 40 天内降到 + 1 °C；
  - 对昼夜温差积分；
  - 按各区水分状态（雨养湿润、雨养半干旱、灌溉）乘土壤水分因子；
  - f_soil = 0.90，2% 破损颗粒计入初期溶出。
- **需氮曲线**：积温（基温 10 °C、上限 30 °C）进度的 S 形曲线，由 V10 时 25%、吐丝时 60% 的累计吸氮比例标定；单位籽粒需氮 19 kg N/t。
- **取整**：保留占比 2.5–8% 的小组分（多为约 5% 尿素）参与取整枚举，不像稻麦版那样直接去掉。玉米苗期靠这部分尿素供氮，直接去掉会使总氮量大增。
- **分次施尿素对照**：基肥 40% + V10 追肥 60%。
- **S 型情景的 β 取 2.0**：这是 `../analysis/beta_scan.py` 扫描出的玉米最优值；稻麦地图用的是 2.5。
- **稳健约束**：同一配方须在常年、偏冷 1.5 °C、偏暖 1.5 °C 三种年份都不断顿。

文件：

| 文件 | 内容 |
|---|---|
| `maize_zones.py` | 28 个产区：代表站、月均温、播种/V10/吐丝/成熟日期、产量、土壤供氮、当地常规施氮、种植系统与水分状态 |
| `maize_model.py` | 释放、需氮、氮库与优化模型 |
| `build.py` | 计算全部产区，生成 `data.json` 和 `index.html` |
| `template.html` | 页面模板 |

模块名带 `maize_` 前缀，是为了与小麦版的 `model.py`、`zones.py` 同时被 `../analysis/beta_scan.py` 导入时不冲突。

## 运行

```bash
pip install numpy scipy
python build.py        # 4 核约 1 分钟
```

## 局限

- 产区数据是初版文献值：气温为代表站月均温近似值，农时、产量、土壤供氮、当地常规施氮取自文献与公开统计的代表值。
- 土壤水分按三类水分状态的周期变化处理，没有用逐日降水。
- 美国玉米带常用秋施或播前施无水氨，模型只比较播种时一次基施。
